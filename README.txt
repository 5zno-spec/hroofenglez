أهلًا ABC - لعبة تعليم الإنجليزية للأطفال
==========================================
الرابط: https://5zno-spec.github.io/hroofenglez/

index.html            : كود اللعبة. الصور والأصوات تُحمَّل منه عند الحاجة فقط.
                        فيها ثلاث لوحات: الحروف (A-Z)، الأرقام (1-10)، الألوان (8).
                        لكل حرف ورقم: استماع واختبار وكتابة. لكل لون: اختبار.
sw.js                 : يحفظ ما استُعمل من صور وأصوات على الجهاز، فتعمل اللعبة بعدها بلا إنترنت.
manifest.webmanifest  : يسمح بتثبيت اللعبة على الشاشة الرئيسية كتطبيق.

audio/          أصوات الحروف A-Z (A.mp3 ... Z.mp3)
audio/praise/   عبارات الثناء
audio/numbers/  الأرقام one ... ten
audio/words/    كلمات الحروف (apple.mp3 ... zebra.mp3)
audio/colors/   الألوان (red.mp3, blue.mp3, ...)
images/         صور الكلمات (apple.webp ... zebra.webp) بخلفية شفافة، WebP بارتفاع 400
images/logo.webp           الشعار (شاشة التحميل والواجهة)
images/space.webp          خلفية الفضاء
images/og.jpg              صورة المعاينة في مواقع التواصل (1200x630)
images/icon-*.png, apple-touch-icon.png  أيقونات التطبيق

لاستبدال صوت أو صورة:
1) ارفع الملف الجديد بنفس الاسم والمسار تمامًا (استبدال).
2) افتح sw.js وغيّر رقم الإصدار، مثلًا ahlan-abc-v1 إلى ahlan-abc-v2،
   وإلا ستبقى الأجهزة التي لعبت من قبل تشغّل النسخة القديمة المحفوظة.

لإضافة ملف باسم جديد: عدّل المسار داخل const AUDIO / NUMAUDIO / WORDAUDIO / COLORAUDIO / PRAISE / PICS في index.html.
اللعبة تعمل أيضًا بفتح index.html من الجهاز مباشرة، بشرط بقاء المجلدات بجانبه.
