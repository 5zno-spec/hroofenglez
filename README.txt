جمّول يعلّمني الإنجليزية - Jammool English game
==============================================
index.html : اللعبة كاملة في ملف واحد (الأصوات مضمّنة داخله). افتحه مباشرة في المتصفح.
audio/     : تسجيلات الحروف الأصلية A-Z، وفي audio/praise عبارات الثناء، وفي audio/numbers
             أصوات الأرقام one-ten (للرجوع إليها فقط؛ المستخدم فعليًا هو المضمّن في index.html).

لاستبدال صوت حرف: حوّل الملف الجديد إلى base64 واستبدل قيمته داخل
const AUDIO={...} في أول وسم <script> في index.html.

لاستبدال صوت رقم: نفس الطريقة، لكن القيمة داخل const NUMAUDIO={...} (المفاتيح one..ten).
